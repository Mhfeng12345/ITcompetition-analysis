# 中国软件开发岗位竞争度分析

基于 BOSS 直聘、猎聘、拉勾、脉脉、CSDN 等平台数据，对中国 27 个软件开发岗位的竞争度进行可视化分析。

## 功能特性

- **岗位概览卡片** — 5 大类别（前端、后端、客户端、游戏开发、其他）的岗位数、平均竞争度、需求趋势
- **雷达图** — 从竞争度、AI 替代风险、入门难度、薪资水平、需求趋势 5 个维度对比各类别
- **四象限散点图** — 岗位竞争度 vs 需求趋势分布
- **薪资排行榜** — 27 个岗位的年薪对比
- **历年需求趋势** — 2018-2026 年各岗位需求变化折线图
- **市场规模趋势** — 柱线组合图展示市场容量与需求趋势
- **详细数据表格** — 包含所有岗位的完整指标数据

## 技术栈

- **框架：** Vue 3（Composition API + `<script setup>`）
- **构建工具：** Vite
- **图表库：** ECharts + vue-echarts

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器（端口 10127）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```
